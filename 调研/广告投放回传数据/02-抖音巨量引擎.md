# 抖音 / 巨量引擎：投流后能拿到的数据

投放后台：**巨量引擎**（广告升级版：项目 → 广告）。开放平台可拉 **自定义报表 / 升级版数据报表**。

示例界面：[示例图片/oceanengine-report-example.png](示例图片/oceanengine-report-example.png)

## 报表类型（你能拉的不只一张消耗表）

开放平台常见分类：

| 类型 | 内容 |
| --- | --- |
| 自定义报表 | 维度 + 指标自由组合 |
| 消耗 / 竞价投放 | 日常效果 |
| 品牌投放 | 品牌广告 |
| 直播分析 | 直播间受众与行为 |
| 落地页 | 橙子建站 / 第三方落地页 |
| 异步下载任务 | 大批量导出 |

后台「自定义报表」维度分组大致包括：时间、项目设置、广告设置、投放信息、素材信息。指标分组：基础、事件、行业。

交叉限制（官方产品说明常见例子）：

- 省份/城市 **不能** 和 性别、年龄、网络 随便交叉。  
- 次留、付费金额、计费时间类指标 **不能** 和部分投放信息维度交叉。  
- **小时粒度** 与平台、省份、城市等维度互斥。

## 分析维度（API / 升级版报表常见字段）

| 字段 | 中文 | 说明 |

| advertiser_id | 广告账号 ID | 必有 |

| province_name / city_name | 省 / 市 | 与部分维度互斥 |
| image_mode | 素材类型 | 大图 / 视频等 |
| landing_type | 推广目的 | |
| external_action | 转化目标 | |
| deep_external_action | 深度转化目标 | |

受众分析报表可按天 + 项目 + 广告 + 性别 + 年龄 拉消耗和展示；文档提到后续可能扩展达人、行为兴趣。

## 点击监测：落地页和 APP 能多拿到一截

凡走巨量落地页，平台会在 URL 后追加类似：

```text
adid=__AID__&creativeid=__CID__&creativetype=__CTYPE__&clickid=__CLICKID__
```

真实请求里宏会被替换。转化回传时把 `clickid` 填进 `context.ad.callback`。

若走 **监测链接**（APP 常见），链接里要带 `__CALLBACK_PARAM__`。点击监测还可能下发（视权限与合规，且多为哈希）：

| 宏（常见） | 含义 |
| --- | --- |
| `__PROJECT_ID__` / `__PROJECT_NAME__` | 项目 |
| `__PROMOTION_ID__` / `__PROMOTION_NAME__` | 广告 |
| `__CID__` | 创意 ID |
| `__CSITE__` | 投放位置（抖音、穿山甲等编码） |
| `__CALLBACK_PARAM__` | 点击回调标识 |
| `__OAID__` / `__IMEI__` / `__IDFA__` 等 | 设备标识（应用监测，受隐私政策约束） |
| `__IP__` / `__UA__` | 网络环境 |
| `__REQUEST_ID__` | 请求 ID |

这些出现在 **你的监测服务收到的点击通知** 里，不会作为「用户实名」出现在广告效果报表中。设备号属于敏感个人数据，数仓要单开权限。

## 对接建议

- 升级版主键：`advertiser_id + cdp_project_id + cdp_promotion_id + 统计日`。  
- 花费一律用 `stat_cost`，不要和财务实付（返点、赠款）直接当同一个「花费」。  
- 转化只认该广告的 `external_action`；深度转化单独字段。  
- 小时报与地域报分表存，避免强行一张宽表笛卡尔积。
