# 小红书聚光：投流后能拿到的数据

投放后台：**聚光平台**（另有专业号推广中心，账户层报表可选择是否合并下载）。

## 你能看到的三块屏幕

| 模块 | 定位 | 你拿到的东西 |
| --- | --- | --- |
| 概览页 | 账户管理 | 总消费、总展现、总点击、点击率、平均点击价格；品牌合作另有曝光、阅读、互动 |
| 推广页 | 当天盯盘 | 实时消耗与效果，可改列 |
| 报表页 | 复盘 | 计划 / 单元 / 创意 / 笔记 / 关键词 / SPU / 定向；近 **400** 个指标，按场景拆成核心 / 实时推荐 / 实时 / 全量四层 |

营销诉求会前置筛选，例如「产品种草、客资收集、应用推广、种草直达」。选错场景会看到一堆用不上的列。

查询习惯：多数维度约 **2 年**历史；单次查询跨度常见上限 **180 天**；定向类型细分往往更短（约近 3 个月）。

## 基础投放指标（所有营销目标都会有）

| 指标 | 含义（投放侧） |
| --- | --- |
| 消耗 / 消费 | 实际花费 |
| 展现 | 笔记/创意在信息流或搜索出现的次数 |
| 点击 | 点进详情或指定落地的次数 |
| 点击率 | 点击 / 展现 |
| 平均点击价格 | 消耗 / 点击 |
| 平均千次展现费用 | 消耗 / 展现 × 1000 |

口径提醒：信息流双列场景下，用户可能 **不点进笔记就点赞/收藏**，所以互动量有时会大于点击量。这不是算错，是产品形态不同。

## 笔记互动指标（种草场景核心）

自定义列里常见分组：**属性（固定） / 基础指标 / 笔记互动指标 / 私信或销售线索**。

| 指标 | 含义 |
| --- | --- |
| 点赞、收藏、评论、分享 | 单次互动行为次数 |
| 关注 | 关注专业号 |
| 互动量 | 上述互动合计（以后台定义为准） |
| 平均互动成本 | 消耗 / 互动量 |
| 行动按钮点击量 / 率 | 笔记组件按钮 |
| 截图、保存图片 | 内容被保存的行为 |

## 客资 / 私信：平台直接给漏斗数

路径：聚光 → 工具 → 线索工具 → **私信分析** / **落地页分析**。范围一般是 **付费流量**，不含自然流量。

### 私信核心卡

| 指标 | 定义要点 |
| --- | --- |
| 私信咨询数 | 点击广告后 24 小时内进入私信聊天页的次数（含组件、主页等） |
| 私信咨询人数 | 同上，按用户去重 |
| 私信开口数 | 进入私信后 **主动发了消息** |
| 私信开口成本 | 消耗 / 开口数 |
| 45 秒首响率 | 45 秒内首次回复 / 总咨询（含自动回复） |
| 3 分钟回复率 | 3 分钟内回复 / 总咨询 |

漏斗：笔记展现 → 笔记点击 → 私信咨询 → 私信开口。还可看咨询来源（底导、主页按钮、组件图片、置顶评论）。

投手口头常说的「进线 / 开口 / 留资」不是同一个字段，字典必须拆开。

### 落地页表单核心卡

| 指标 | 定义要点 |
| --- | --- |
| 落地页访问量 | 进入表单页次数 |
| 表单数 | 成功提交次数 |
| 表单转化率 | 表单数 / 点击数（以后台公式为准） |
| 平均表单收集成本 | 消耗 / 表单数 |
| 平均停留时长 | 总停留 / 访问 |
| 3 秒失跳率 | 停留 ≤3 秒的访问 / 全部访问 |

组件级还可拆：置顶评论组件展现/点击、图片底部组件展现/点击。

三条链路：笔记表单、直跳表单、表单+私信，漏斗节点不同，不能混加。

## 搜索与商品

| 报表 | 内容 |
| --- | --- |
| 关键词 / 搜索主题 | 搜词效果；关键词报表有 **匹配方式** 字段 |
| 搜索词、人群包 | 文档写明可能是 **白名单** |
| SPU 报表 | 按标准化产品看种草/带货 |

## 线索内容（姓名、手机）怎么来

分两条技术方向，不要和「报表上的表单数」搞混：

1. **聚光落地页 → 你的 CRM**  
   平台把已提交的线索 **推送** 给你（表单、部分场景含私信）。这是经营用的个人信息。
2. **你自己的外链落地页 → 回传给聚光**  
   点击时 URL 带 `click_id`，用户提交后你把 `advertiser_id`、`event_type`、`conv_time`、`click_id` POST 回去。平台用它学习出价，报表才有转化。  
   常见事件类型（文档列举）：表单提交 101、有效表单 102、电话拨打 111、加粉、购买、负向样本等。

联调环境的 `click_id` 常以 `atest` 开头，**不会进正式报表**。

## 对接建议（给数据治理）

- 主键建议：`账户ID + 计划ID + 单元ID + 创意/笔记ID + 日期`。  
- 「转化」按营销目标拆成互动、开口、表单、下载，禁止一个字段装所有目标。  
- 线索明细表与投放汇总表分开存，线索表走权限与脱敏。
