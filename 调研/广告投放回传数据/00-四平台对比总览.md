# 四平台投流可回传数据 · 总览

> 数字均为公开文档归纳。平台后台会持续改版，以各后台「自定义列 / 指标字典」为准。

## 1. 你每天能导出的那张表（最常用）

四个后台默认给你的都是 **按广告结构汇总的效果表**，不是用户名单。

| 能力 | 小红书聚光 | 抖音 / 巨量引擎 | TikTok Ads | Google Ads |
| --- | --- | --- | --- | --- |
| 投放后台 | 聚光 | 巨量引擎 / 巨量广告升级版 | TikTok Ads Manager | Google Ads |
| 广告层级 | 账户 → 计划 → 单元 → 创意 / 笔记 | 账户 → 项目 → 广告（升级版） | Advertiser → Campaign → Ad Group → Ad | Account → Campaign → Ad group → Ad / Keyword / Asset |
| 默认核心列 | 消耗、展现、点击、点击率、平均点击价格 | 消耗、展示、点击、CTR、CPC、转化、转化成本 | Cost、Impressions、Clicks、CTR、CPC、Conversions、CPA、ROAS | Clicks、Impr.、CTR、Avg. CPC、Cost、Conv.、Cost/conv. |
| 后台指标体量 | 近 **400** 个，按营销场景分层 | 自定义报表指标很多（基础 + 事件 + 行业） | 界面 50+ 列，API **400+** 指标 | UI 列很多；API 有完整 metrics / segments |
| 导出 | 报表页下载；可含专业号数据开关 | 报表导出 / 开放平台 API | CSV / XLSX；可邮件定时 | 下载报表；API；BigQuery 传输 |
| 历史跨度（常见） | 多数维度约 2 年；一次查询最长约 180 天 | 以开放平台各接口限制为准 | 按账户时区选日期；支持 lifetime | 细粒度日期约 37 个月（API v24 起有限制） |

## 2. 四类指标对照（治理时必须分开存）

同一中文词在四个平台算法不同，字典里应拆成「平台字段名 + 本平台定义」。

| 业务含义 | 小红书 | 巨量引擎（常见字段名） | TikTok | Google Ads |
| --- | --- | --- | --- | --- |
| 花了多少钱 | 消耗 / 消费 | `stat_cost` | Cost / Spend | Cost（API：`metrics.cost_micros`，微单位） |
| 广告出现次数 | 展现 | `show_cnt` | Impressions | Impressions |
| 点了广告 | 点击 | `click_cnt` | Clicks (all) / Clicks (destination) 要分开 | Clicks |
| 点击效率 | 点击率、平均点击价格 | `ctr`、`cpc_platform`、`cpm_platform` | CTR、CPC、CPM | CTR、Avg. CPC、Avg. CPM |
| 平台认定的结果 | 因营销目标而异：互动 / 私信开口 / 表单 / 下载 | `convert_cnt`、深度转化、激活、注册 | Conversions（优化事件）；另有实时转化 | Conversions / All conv.（口径不同） |
| 结果成本 | 开口成本、留资成本、平均互动成本 | `conversion_cost`、`deep_convert_cost` | Cost per conversion / CPA | Cost / conv. |
| 收入效率 | 电商场景有成交相关指标 | ROI 系数、付费类指标（视行业） | ROAS | Conv. value、Conv. value / cost |
| 内容互动 | 赞、藏、评、分享、关注、截图、保存图片 | 播放、3 秒播放、完播、点赞等 | Video views、6s focused views、Paid likes | 视频观看、互动（YouTube / Demand Gen） |
| 覆盖人数 | 有触达类指标（视报表） | 视报表 | Reach、Frequency | 覆盖人数 / 展示频次（部分广告类型） |

## 3. 拆分维度（报表能切、但通常仍是汇总）

| 维度 | 小红书 | 巨量 | TikTok | Google |
| --- | --- | --- | --- | --- |
| 时间 | 分时 / 天 / 周 / 月 | 天 / 小时（小时与部分人群维度互斥） | 天；报表可按时间拆 | 日 / 周 / 月 / 小时等 segments |
| 广告结构 | 计划、单元、创意、笔记、关键词、SPU | 项目、广告、素材类型 | Campaign / Ad group / Ad / Placement | Campaign / Ad group / Keyword / Asset |
| 人群 | 定向报表、人群包（部分白名单） | 性别、年龄、网络、省、市（交叉有限制） | AUDIENCE 报表：年龄、性别、国家、系统等 | 年龄、性别、设备、地域；部分需达到隐私阈值才出数 |
| 搜索 | 搜索主题、搜索词（搜索词可能白名单） | 搜索广告位可筛 | 搜索类投放有对应维度 | **搜索字词报告**是 Google 特有强项 |
| 版位 | 信息流 / 搜索等 | `app_code` 首选位置、投放位置 | Placement（TikTok / Pangle 等） | 搜索 / 展示 / YouTube / 购物等网络 |

注意：人群拆分给你的是 **「18–24 岁女性消耗了多少」**，不是这些人的名单。

## 4. 点击标识（用来对订单，不是用户身份证）

投放外链或店铺时，平台会在落地页 URL 上拼唯一点击串。你保存它，转化时再回传，平台报表里的「转化」才会准。

| 平台 | 标识名称 | 你怎么拿到 | 你拿它做什么 |
| --- | --- | --- | --- |
| 小红书 | `click_id`（新链路；老链路 `trackId` 已切走） | 用户点击后跳转 URL 自动拼接 | 把表单/深转事件 POST 回聚光，用于归因和学习 |
| 巨量引擎 | `clickid` / `__CALLBACK_PARAM__` | 落地页自动拼 `adid` `creativeid` `clickid`；监测链接用 callback | 调事件管理回传 API，写入 `context.ad.callback` |
| TikTok | `ttclid` | 点击后自动追加到落地页（不必手写进 UTM） | Pixel / Events API 用它把转化对回广告 |
| Google | `gclid` | 打开自动标记后追加 | 转化导入、GA4、离线转化；API `click_view` 可按点击查（近 90 天、一次一天） |

这些 ID **可以**进你的数仓，作为「点击 → 会话 → 订单」的关联键。  
它们 **不是** 姓名、手机号；不要当成用户主数据。

## 5. 线索 / 订单：哪些是平台给的，哪些是你自己的

| 场景 | 小红书 | 抖音 | TikTok | Google |
| --- | --- | --- | --- | --- |
| 站内私信开口 | 平台报表有咨询数、开口数、开口成本、首响率 | 企业号/私信类产品另有线索工具 | Inbox / Instant Form 视产品 | 无对等「私信」 |
| 平台落地页表单 | 表单数、停留、3 秒跳出；可通过 API **把线索推到你的 CRM** | 橙子建站 / 线索通可回传或推送线索 | Instant Form 可导出线索 | Lead Form 扩展可收线索 |
| 你自己的落地页 | 你必须用 `click_id` **回传**转化，平台才认 | 必须回传 clickid/callback | Pixel + Events API | 网站转化标签 / GA4 / 增强型转化 |
| 店铺成交 | 电商/SPU 报表（站内） | 千川等电商产品另算 | TikTok Shop 有站内成交指标 | 购物广告有商品维度；独立站成交靠转化跟踪 |

**手机号、微信、姓名**：只有用户在表单/私信/订单里交给你（或交给平台线索产品再推给你）时才有。这是合规上的「一方经营数据」，要按个人信息保护来管，不能和广告报表混成一张宽表随便给全员看。

## 6. 取数通道

| 通道 | 适合 | 四平台情况 |
| --- | --- | --- |
| 后台看数 | 投手盯盘 | 都有概览 + 自定义列 |
| 下载 CSV/Excel | 对账、周报 | 都支持；TikTok 还可定时发邮件（约 5 人） |
| 开放 API | 进数仓、自动看板 | 巨量开放平台、TikTok Marketing API、Google Ads API；小红书以聚光开放能力 / 线索 API 为主，报表 API 权限以官方最新开通条件为准 |
| 点击监测 | MMP / 自建归因 | 巨量监测链接宏参数最全（含设备号哈希，APP 场景）；Google 有 `click_view` |

## 7. 明确拿不到的（四个平台共性）

1. 仅曝光、未转化用户的真实身份。  
2. 把四个平台用户打通成同一个自然人的官方 ID（没有这种跨平台身份证）。  
3. 完整原始点击日志无限回溯（Google 点击级大约 90 天且按天查询）。  
4. 未达隐私阈值的过细人群交叉（年龄 × 性别 × 小区 往往被压掉）。  
5. 把「平台归因转化」直接当成财务确认收入——窗口、模型、重复归因都会让数字偏大。
