# 海外拓客集团 · 数据治理平台 Demo

面向约 300 人规模、以**广告投放**和**海外店铺运营**为主业的集团，建设一套轻量数据治理与统计看板 Demo。

数据体量约数万条，痛点不在算力，而在**多源口径不一致**。平台要先把标准与数据字典立住，再按角色出看板。

## Demo 原型

可交互前端在 [`demo/`](demo/)：

```bash
cd demo
npm install
npm run dev
```

已接入调研四平台示例 CSV 字段，含经营总览、投放工作台、店铺运营、数据字典、主数据、质量中心与角色切换。
