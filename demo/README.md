# 数据治理 Demo 原型

基于 `调研/广告投放回传数据` 中的四平台字段与示例 CSV 搭建的可交互原型。

## 启动

```bash
cd demo
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 http://localhost:5173 ）。

## 包含模块

| 模块 | 说明 |
| --- | --- |
| 经营总览 | 净销售额、花费、经营 ROAS、MER；强调禁止平台转化加总 |
| 投放工作台 | 小红书 / 巨量 / TikTok / Google 计划明细（调研样例字段） |
| 店铺运营 | 漏斗、客单、退款、TOP SKU |
| 数据字典 | 12 个黄金指标 + 平台字段映射 |
| 主数据 | 店铺、账户、渠道枚举、SKU、汇率 |
| 质量中心 | 评分与问题工单 |
| 数据接入 | 源 CSV 与点击标识对照 |

左下角可切换角色（老板 / 投放 / 运营 / 财务 / 管理员），菜单随权限变化。点击指标编码（如 M003）可打开口径抽屉。

## 数据说明

- 投放明细来自调研示例表，并补充一方订单用于计算经营 ROAS。
- 汇率：USD=7.2、GBP=9.15（Demo 月平均，字典中标注待确认）。
- 数字均为虚构，仅用于演示口径与治理流程。
